## ✨ 为什么用这个？

想象一下：月底了，几十个仓库/部门各发来一张 Excel，你要把它们拼成一张总表。

手动干：一个个打开、一行行复制粘贴、列名对不上还要自己调、对错全靠肉眼比……**一下午就这么没了，还可能出错。**

用这个工具：**双击 → 选模板 → 选文件 → 喝口茶，几十张表几秒就并成一张，还能顺带出一份"哪张表、哪一列有问题"的审计报告。**

| 痛点 | 解决 |
|------|------|
| 列名不一致 | 自动匹配 + 检测异常（丢失列/多余列/同名列冲突） |
| 格式难统一 | 以模板表为基准，严格按列对齐；openpyxl 保真写入，样式/宏不丢 |
| 出错了不知道 | 生成完整异常记录表，逐条可追溯 |
| 不会写代码 | 双击 exe，图形化对话框，零编程门槛 |
| 装环境麻烦 | 纯 Python 标准库即可运行；openpyxl 可选（缺失自动降级） |
| 大表需要拆分 | 内置拆分脚本，按列值一键拆分多 Sheet 大表 |

## 🚀 别的工具做不到的，它做到了

> 市面上能"合并 Excel"的工具有很多，但**能同时做到下面这几件事的，寥寥无几**——这恰恰是它存在的理由：

1. **🎨 格式保真：样式、公式、图表、合并单元格一个不丢** —— 多数工具是"读数据→重写全新表格"，你模板里调好的列宽、颜色、公式、图表全被冲没了。它是以模板为「底」只填数据，其余原样保留，合并完肉眼看不出是机器干的。
2. **🔐 .xlsm 宏工作簿照样无缝处理** —— 带宏的表格是多数工具的死穴，要么跳过、要么宏被破坏。它能读宏工作簿、`keep_vba` 保留宏，且**输出格式自动跟随模板**（`.xlsm` 进 → `.xlsm` 出），打开结果宏还能正常跑，真正做到"像人肉填表"。
3. **🧠 同名列"三步判断"** —— 小表里出现两个"备注"列？它按「值一致→全填 / 数量相等→顺序 / 多于→弹窗问你」来智能决策，而不是报错罢工，或默默选错列埋雷。
4. **🔗 拆分→合并一键闭环** —— 拆分产出的文件，文件名=拆分值、Sheet 名=原 Sheet 名，直接就能当合并的输入，中间不用任何手工改。单 Sheet 还能"以拆分值重命名 Sheet"，配合合并端兜底弹窗，拆、合彻底打通。
5. **👀 写入前"匹配总览"预览 + 实时列名匹配度** —— 不像别的工具"点一下直接出结果，错没对只能事后翻"，它在写文件前先给你一张清楚的映射总览（✅/⚠️），手动指认时还能实时看到"匹配了几列"，心里有底再动手。
6. **🧾 全程可审计** —— 每一次丢弃、截断、取消、跳空行都写进异常记录表 + 日志，事后哪张表哪一列出了什么问题，一条条查得出来，不是黑盒。

## 🔧 两大工具

### 📥 合并脚本（合并脚本.py）

将多个结构相似的 Excel/CSV 小表按列名智能匹配合并到统一的模板表中。

```
双击 合并脚本.exe
      │
      ▼
  选择模板文件 + 可选"标注数据来源"
      │
      ▼
  选择待合并文件（多选，模板可参与合并）
      │
      ▼
  逐文件处理：遇到异常弹窗询问 → 用户决策
      │
      ▼
  生成 合并结果.xlsx（含异常记录 & 审计日志）
```

**V1.4 新增：**
- 拆分 → 合并闭环 Sheet 名策略，两脚本无缝衔接

**V1.5 新增：**
- openpyxl 模板保真写入：完整保留 Sheet/样式/图表/公式/合并单元格/格式
- 匹配总览确认：合并前展示匹配结果，确认后再执行
- 合并结果覆盖更新（修复在职/试用期数据被追加到空行区之后）
- 修复工号 / OA 上级工号等文本数字列前导零丢失
- 兼容 inlineStr 内联字符串（修复花名册读取为空/无列名）
- **支持 `.xlsm` 宏工作簿**：可作为模板/小表，`keep_vba` 保留宏；结果格式跟随模板（`.xlsm` 模板 → `.xlsm` 结果，实现"填数据"体验）

**V1.3 新增：**
- "标注数据来源"可选（checkbox，默认勾上，向前兼容）
- 模板文件可被合并（列表标记 📌，默认不勾）
- 弹窗定位统一，不再跳来跳去
- 输出文件自动递增防覆盖（`合并结果_2.xlsx`...）

### 📤 拆分脚本（拆分脚本.py）

将一张含多 Sheet 的大表，按每个 Sheet 各自选定的列值拆分为多个小表文件。

```
双击 拆分脚本.exe
      │
      ▼
  选择大表文件（单选）
      │
      ▼
  配置每个 Sheet：勾选参与 + 选择拆分依据列
      │
      ▼
  生成 拆分输出/ 文件夹
      ├── 值A.xlsx  （含所有选中 Sheet，Sheet 名保留原名）
      ├── 值B.xlsx
      └── 值C.xlsx
```

**特性：**
- 每个 Sheet 独立选择拆分依据列
- 不同 Sheet 可选用不同列拆分
- 拆分列值取并集，同值自动汇入同一文件
- 文件名 = 拆分列值，Sheet 名 = 原始 Sheet 名（完美衔接合并脚本）
- 输出文件夹自动递增防覆盖（`拆分输出_2/`...）
- 非法文件名字符自动替换，空值行自动跳过

## 📋 合并脚本功能一览

### 智能文件管理
- 自动扫描目录内所有 `.xlsx` / `.xlsm` / `.csv` 文件
- 图形化单选模板 + 多选待合并文件（勾选变色 + 全选按钮）
- 排除 `~$` 临时锁文件

### 列名匹配 & 冲突处理

| 场景 | 行为 |
|------|------|
| 列名完全一致 | 自动匹配，按列填值 |
| **同名列**（小表多列同名） | 三步判断：值一致→全填 / 数量相等→顺序 / 多于→逐列弹窗 |
| 列名不存在于模板 | 弹窗确认后丢弃，记录异常 |
| 数据列数超过表头 | 弹窗确认后截断，逐额外列记录 |
| 表头有空列名 | 弹窗确认后丢弃，标注"数据异常，无列名" |

### 结果输出

| Sheet | 内容 |
|-------|------|
| 模板 Sheet(s) | 模板表头 + 所有合并数据行 |
| `异常记录` | 四种异常类型的完整记录（含前 5 行数据值、列位置、用户操作） |
| `取消合并的表名` | 被取消合并的文件及原因 |

### 异常记录样例

```
文件名     Sheet    行号    列名             列1位置  列1值        异常类型
小表3.xlsx  NAME1   全部行   数据异常，无列名    C       v1,v2,v3    无列名
小表3.xlsx  NAME1   全部行   -                 I       45,67,AA;    超表头列数
小表2.xlsx  NAME2   -       111               L       111,222       列名不存在于大表
小表1.xlsx  NAME1   -       T                 K       落选值1,2     同名列未选择
```

## 🚀 本地运行 / 打包

### 直接运行

```bash
# 仅需标准库（Python 自带）即可启动
python 合并脚本.py
python 拆分脚本.py
```

> 💡 **v1.5 起**：若需「模板保真写入 / `.xlsm` 宏保留」能力，请额外安装 openpyxl：
>
> ```bash
> pip install openpyxl
> ```
>
> 未安装 openpyxl 时脚本会自动降级为标准库读写模式（v1.3 的能力），不影响基本合并拆分。

### 打包为 exe

```bash
pip install pyinstaller openpyxl
pyinstaller --onefile --console 合并脚本.py
pyinstaller --onefile --console 拆分脚本.py
```

> 使用 `--console` 保留控制台窗口，方便查看进度和日志。
> 打包 exe 时如需保真写入，请先 `pip install openpyxl`，PyInstaller 会自动将其打入。

## ⚠️ 约束 & 边界

- **合并脚本**：模板文件第 1 列如勾选"标注数据来源"则必须为 `表名`
- Excel 支持 `.xlsx` / `.xlsm` 宏工作簿（不支持 `.xls`）
- CSV 以 UTF-8 读取，映射到虚拟 Sheet `Sheet1`，仅当模板含同名 Sheet 时匹配
- Windows tkinter 不支持 `pady=tuple` 写法（`pady=(15,5)` 报 `bad screen distance`），间距必须用单整数
- **拆分脚本**：Sheet 名最长 31 字符（Excel 限制），非法文件名字符自动替换

完整边界情况见 [PRD](PRD_Excel小表并大表工具.md)。
